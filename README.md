# JARVIS Gemini AI

## Install

Make sure Node.js 18+ is installed.

Open the JARVIS folder in Command Prompt.

Run:

npm install

Then:

npm start

Open:

http://localhost:3000

## Gemini API key

Create a `.env` file:

GEMINI_API_KEY=YOUR_KEY_HERE
GEMINI_MODEL=gemini-2.5-flash
PORT=3000

Never upload `.env` to GitHub.

## Voice

Use Chrome or Edge.

Click:

ACTIVATE JARVIS

Then allow microphone access.

After activation say:

Hey JARVIS

For example:

Hey JARVIS, explain artificial intelligence.

Hey JARVIS, search YouTube for Python tutorials.

Hey JARVIS, what is the capital of India?

JARVIS will send the command to Gemini.

## Microphone test

Use:

TEST MICROPHONE

If it says:

MICROPHONE WORKS

your browser can access the microphone.

If it says:

MICROPHONE BLOCKED

allow microphone access from the browser's address-bar permissions.
